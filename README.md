# anki-deck-gen-tgbot

Telegram-бот и CLI, которые делают колоды Anki из таблиц. Преподаватель заполняет
таблицу в Google Sheets или Excel, присылает боту файл, ссылку или просто текст —
и получает `.apkg`, который открывается в Anki двойным щелчком. Слова и фразы можно
озвучить (gTTS).

## Как пользоваться (для преподавателя)

1. Сделайте таблицу. Первая строка — заголовок: колонки **Q** и **A** (или **Вопрос**
   и **Ответ**). По желанию — **Deck**/**Колода** (подколода) и **Tags**/**Метки**
   (метки через запятую). Если листов несколько, каждый лист становится подколодой.
   Готовый шаблон пришлёт команда `/template`.
2. Пришлите таблицу боту одним из способов:
   - файлом `.xlsx` или `.csv`;
   - ссылкой на Google Таблицу — сначала откройте доступ: «Настройки доступа» →
     «Все, у кого есть ссылка» → «Читатель»;
   - текстом, по строке на карточку: `How are you? — Как дела?` (минимум две строки).
3. Бот покажет сводку: сколько записей, есть ли проблемные строки (пустой вопрос или
   ответ). Их можно исправить прямо в чате, пропустить или отменить всё.
4. Выберите **тип записи** — как в Anki: `Простая`, `Простая (с обратной карточкой)`,
   `Простая (с вводом ответа)`. Затем языки и озвучку: одна кнопка для типичного
   случая «English → Русский, озвучен English», «Без озвучки», «Как в прошлый раз»
   или «Настроить…».
5. Через несколько секунд придёт файл. Откройте его в Anki.

Доступ к боту — по приглашению: админ присылает одноразовую ссылку (`/invite`).
Посторонним бот не отвечает.

## Запуск локально

```bash
uv sync
cp .env.example .env          # TELEGRAM_BOT_TOKEN, ADMIN_IDS, при необходимости TELEGRAM_PROXY
uv run python -m anki_deck_gen
```

На ноутбуке Telegram доступен только через mihomo: `TELEGRAM_PROXY=http://127.0.0.1:1082`.
База доступа создаётся сама (alembic на старте), по умолчанию — `anki-deck-gen.sqlite`
в текущем каталоге.

## CLI

Та же сборка без Telegram и без токена:

```bash
uv run anki-deck-gen --source table.xlsx --note-type basic-reversed \
    --lang-pair en,ru --audio-for q --deck-name "At the appointment" --output-dir out
```

`--source` принимает путь к `.xlsx`/`.csv`/`.txt`, ссылку на Google Sheets или `-`
(текст со stdin). `--audio-for`: `none` / `q` / `a` / `both`. Проблемные строки
печатаются с номерами, сборка не идёт — правьте файл. Картиночные колоды
(`<img src="…">` в полях) — только через CLI с `--media-dir`.

Кэш озвучки — `MEDIA_CACHE_DIR` (по умолчанию `WORK_DIR/media`): одна фраза на одном
языке озвучивается один раз за всю жизнь.

## Свои типы записей

Тип записи — класс в `src/anki_deck_gen/notetypes/`, зарегистрированный декоратором
`@register`. Стоковые повторяют шаблоны Anki байт в байт; кастомный пример —
`vietnamese.py` (раскраска тонов, дополнительные колонки `Tips`/`Dialect`/`Note`/`Example`).
Новый модуль + одна строка импорта в `notetypes/__init__.py` — и тип виден в CLI и в
боте. Правило: изменили поля типа — смените `model_id`.

## Разработка

```bash
uv run ruff check . && uv run ruff format --check . && uv run mypy src tests && uv run pytest -q
```

CI (`.github/workflows/ci.yml`, job `ci`) гоняет то же плюс gitleaks, сверку
`requirements.txt` с `uv.lock` и пинов с портами FreeBSD. Деплой — по тегу `vX.Y.Z` с
зелёным CI, см. `docs/DEPLOY.md`. Решения — `docs/ARCHITECTURE.md`, словарь — `CONTEXT.md`.

В репозитории нет колод и данных пользователей — только код и синтетические примеры.
Локальные таблицы для регрессии лежат в gitignored `local/`.
